# Critical-to-medium bug audit — 2026-09-19

This report records confirmed critical, high, and medium issues found during a
repository audit. Low-severity findings and general lint debt are intentionally
out of scope.

## Critical

### Vulnerable Next.js runtime

- **Affected version:** `next@16.2.2`
- **Impact:** the installed release is covered by published advisories for
  unauthenticated remote code execution, Proxy authorization/rate-limit bypass,
  server-side request forgery, cache poisoning, cross-site scripting, and
  denial of service.
- **Relevant surface:** the application uses App Router route handlers and a
  `src/proxy.ts` rate-limit boundary.
- **Remediation:** upgrade to the patched `next@16.3.5` release and verify a
  production build.

## High

### Vulnerable Better Auth release

- **Affected version:** `better-auth@1.6.17`
- **Impact:** pre-account hijacking is possible in affected magic-link and
  email-OTP sign-in flows.
- **Remediation:** upgrade to a patched Better Auth release and verify all auth
  route types at build time.

### Mobile auth forwards credentials to a request-controlled origin

- **Affected routes:** `/api/auth/mobile-login` and
  `/api/auth/mobile-register`
- **Impact:** the routes construct an internal auth URL from `req.nextUrl.origin`.
  In deployments where the Host or forwarded-host header reaches Next.js, an
  attacker can cause submitted email/password request bodies to be forwarded to
  an attacker-controlled origin.
- **Remediation:** invoke Better Auth's server API directly instead of making a
  host-derived HTTP request.

### Vulnerable mail, CSS, image, and XML processing dependencies

- **Affected packages:** Nodemailer, PostCSS, Sharp, `@xmldom/xmldom`,
  `image-size`, and their dependency chains.
- **Impact:** the reported advisories include header injection, file-read/SSRF
  bypasses, XML injection, and denial of service.
- **Remediation:** update direct and transitive dependencies to patched releases,
  then rerun the production and client builds.

## Medium

### Folder rename/delete treats names as SQL wildcards

- **Affected route:** `/api/vault/folders`
- **Impact:** folder names containing `%` or `_` are interpolated into SQL
  `LIKE` patterns. Renaming or deleting such a folder can modify unrelated
  sibling folders that match the wildcard pattern.
- **Remediation:** use literal prefix matching rather than pattern matching.

### Concurrent attachment uploads can exceed storage quota

- **Affected route:** `/api/vault/attachments`
- **Impact:** quota is checked with separate reads before the attachment row and
  usage counter are written. Concurrent uploads can observe the same usage value,
  all pass, and collectively exceed the configured quota.
- **Remediation:** reserve quota with a conditional atomic update in the same
  database transaction as the attachment row insertion; roll back and delete the
  uploaded object when the reservation fails.

## Baseline verification

- `npm run build`: passes before remediation.
- `npm run lint`: fails with 468 errors and 302 warnings already present across
  web, extension, and mobile sources. This existing lint backlog is not treated
  as a newly introduced bug in this audit.
- `npm audit --omit=dev`: reports 34 production dependency vulnerabilities
  (1 critical, 11 high, 21 moderate, 1 low) before remediation.
